(Linux) `ifconfig` will give information regarding one's NIC and IP addressing.
(Windows) `ipconfig`
`tun0` indicates a VPN in use
`eth0` indicates public in use

### IP Addressing
IP is considered the phone number and the netmask the area code.
And the default gateway acting as the router to the network.

### Checking the Routes
Using commands such as `netstat -r`, will provide with the ip route of the network. Other commands being `ip route`.
